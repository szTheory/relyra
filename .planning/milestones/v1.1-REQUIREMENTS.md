# Requirements: Relyra v1.1

**Defined:** 2026-05-23  
**Milestone:** v1.1 — Verify the Trust Path  
**Core Value:** Every SAML login ends in a verified trust path or a typed rejection — never a silent compromise.

## v1.1 Requirements

Committed scope for v1.1 closed the published SAML auth-bypass by proving canonicalization correctness, wiring real XMLDSig verification into response and metadata paths, permanently gating adversarial regressions, and staging the disclosure artifacts for release.

### Signature Verification

- **SIGV-01**: Response and assertion XMLDSig signatures are cryptographically verified against the configured IdP certificate's public key, never document `KeyInfo`.
- **SIGV-02**: `DigestValue` is recomputed over the canonicalized referenced element and compared; tampered signed content is rejected.
- **SIGV-03**: Verification uses correct exclusive XML canonicalization over a real parse tree behind the `Relyra.Security.XML` seam.
- **SIGV-04**: Metadata-root signatures are cryptographically verified using the same primitive, with operator-pinned trust anchors preserved as defense-in-depth.

### Adversarial Assurance

- **ASSUR-01**: A permanent adversarial corpus proves rejection of forged-signature, tampered-content, wrong-key, digest-mismatch, and canonicalization-differential inputs, and remains green under `mix ci.security`.
- **ASSUR-02**: `Relyra.TestSupport.FakeIdP` performs real XMLDSig signing so the suite exercises genuine verification.

### Disclosure & Honesty

- **DISC-01**: `docs/security_boundary.md`, `SECURITY_REVIEW.md`, and `docs/security_findings.md` describe the actual verification guarantee and record the finding with disposition.
- **DISC-02**: A coordinated GHSA/CVE/release-note advisory draft is prepared for publication at the fixed release, marking `1.0.0`/`1.1.0` affected.
