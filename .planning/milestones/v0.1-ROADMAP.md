# Milestone v0.1: SP-initiated SSO, verified end-to-end

**Status:** ✅ SHIPPED 2026-04-25
**Phases:** 1-6
**Total Plans:** 19

## Overview

Relyra v0.1 shipped as a strict-by-default SAML SP library for Phoenix teams: hardened XML trust boundaries, strict protocol validation, stable behaviour contracts and stores, Phoenix runtime integration, observability, and adopter-facing docs/release tooling.

## Milestone Summary

**Key Decisions:**

- Pure-BEAM XML parsing was selected as the default trust boundary implementation.
- RelayState stayed opaque and server-side only.
- Request and replay stores shipped as behaviour-backed adapters with ETS dev defaults and optional Ecto support.
- Telemetry became a first-class catalog, not ad hoc instrumentation.
- Release discipline and adopter docs were added before v0.1 closeout.

**Issues Resolved:**

- Fail-open protocol trust paths were closed.
- Replay and request-intent gating became atomic and typed.
- Provider, installer, and release surfaces were hardened for first adopters.

**Issues Deferred:**

- Ecto schemas, metadata import/export, and certificate rollover move to v0.2.
- LiveView admin moves to v0.3.
- IdP-initiated SSO and SLO remain later milestones.

**Technical Debt:**

- Future work still needs persisted enterprise configuration and rollover UX.
- v0.1 release hardening should be revisited when v0.2 adds metadata persistence.
