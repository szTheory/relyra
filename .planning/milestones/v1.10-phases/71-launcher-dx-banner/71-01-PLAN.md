## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shell environment → Make recipes | Untrusted override values enter displayed URLs and Docker Compose substitution. |
| operator input → destructive target | Interactive or non-interactive confirmation gates named-volume deletion. |
| legacy Bash adapter → Make | User-supplied verb selects one of six fixed target names. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-71-01 | Tampering / Elevation | Makefile environment expansion | high | mitigate | Quote shell values, keep command names literal, forbid `eval`/shell-fragment execution, and assert exact Compose variables in the focused test. |
| T-71-02 | Denial of service | `nuke`, `reset`, `reseed`, `down` | high | mitigate | Separate volume deletion into confirmed `nuke`, default confirmation to no, require `NUKE=1` non-interactively, and scope teardown to the Relyra Compose project. |
| T-71-03 | Information disclosure | banner/help/example environment | medium | mitigate | Print variable-derived origins only, never credential values; keep `.env.example` commented and explicitly demo-only. |
| T-71-04 | Spoofing | `scripts/demo` dispatch | low | accept | The adapter is local developer tooling and maps an exact closed verb set to literal Make targets; invalid input exits nonzero with usage. |

No npm, pip, or cargo package install occurs in this plan; the package-legitimacy supply-chain gate is not applicable. Generic shell injection is canon and is covered by the concrete T-71-01 mitigation plus later `$gsd-secure-phase`; it is not duplicated as a bespoke prohibition.
