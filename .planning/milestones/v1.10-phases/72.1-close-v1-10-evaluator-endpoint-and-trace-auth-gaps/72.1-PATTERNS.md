### Fail-closed admin authentication

**Source:** `demo/ledger_loop/lib/ledger_loop_web/plugs/demo_admin_auth.ex` lines 14-39 and router lines 63-72.  
**Apply to:** trace tests, launcher/docs wording, and no new auth implementation.

```elixir
case configured_credentials() do
  {:ok, username, password} ->
    conn = Plug.BasicAuth.basic_auth(conn, username: username, password: password)
    if conn.halted, do: conn, else: assign(conn, :demo_admin_principal, @principal)

  :error ->
    conn |> Plug.BasicAuth.request_basic_auth() |> halt()
end
```

The whole admin login and admin mount already use the demo-admin pipeline. Preserve it: no defaults, checked-in credentials, or bypasses.

### Runtime-only secrets and deterministic docs evidence

**Source:** `.env.example` lines 13-16; `test/docs/demo_guide_drift_test.exs` lines 261-271.  
**Apply to:** Compose, Make, docs, and tests.

Credentials can be named and empty-forwarded only. Do not echo, persist, or demonstrate usable secret values. Static artifact checks and focused request tests are the deterministic evidence.
