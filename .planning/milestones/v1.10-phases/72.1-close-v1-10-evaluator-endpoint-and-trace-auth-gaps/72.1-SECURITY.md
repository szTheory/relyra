> Per-phase security contract for the evaluator endpoint and runtime-authenticated trace closure.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Enabled connection → Setup UI | Persisted connection identity selects the operator-facing mounted SAML endpoints. | Connection ID and derived route URLs |
| Browser → SAML/admin routers | Browser-controlled navigation reaches metadata, login, ACS, admin login, and protected trace behavior. | Route parameters, SAML messages, Basic Auth credentials |
| Host environment → Compose/Playwright | Operator-provided or per-run credentials enter isolated demo processes. | Demo admin username/password |
| Make/docs → operator | Public instructions determine credential setup, recovery, and topology navigation. | Shell commands, variable names, route guidance |
| Containers → retained diagnostics | Failure evidence crosses from runtime processes into retained files. | Logs potentially containing credentials, headers, cookies, XML, or PEM material |
