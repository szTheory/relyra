<objective>
Close CR-01 by requiring genuine runtime-configured host-admin authentication before either the demo admin scope can be established or any mutation-capable LiveAdmin route can be entered, then update the Keycloak proof to use that boundary.

Purpose: The existing public GET shortcut converts any caller into the same scope that can change SAML connections, metadata, certificates, and mappings. KC-01 cannot rely on that privilege escalation for Login Trace evidence.
Output: A deny-by-default demo admin pipeline, adversarial route/session tests, and an attachment-free browser proof using ephemeral host-admin credentials.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| unauthenticated browser -> LedgerLoop admin routes | Public localhost requests must not establish or enter mutation-capable scope. |
| runtime environment -> DemoAdminAuth | Host-admin credentials enter the demo process without becoming source defaults or caller-controlled principal fields. |
| authenticated request -> signed Phoenix session -> LiveAdmin scope | Only the fixed authenticated principal may create the session values consumed by AdminScope. |
| E2E harness -> Playwright/Compose -> diagnostics | The ephemeral admin secret crosses processes but must not reach Keycloak, logs, attachments, or retained text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-70-35 | Elevation of privilege | `/login/admin` session bootstrap | high | mitigate | Put the route behind `DemoAdminAuth`, derive session principal only from its fixed authenticated assignment, and test unauthenticated/wrong credentials for 401 plus absent scope keys. |
| T-70-36 | Elevation of privilege | mounted `/relyra/admin` mutation routes | high | mitigate | Mount every LiveAdmin route inside the same authenticated router scope and test a representative mutation-capable path before scope resolution. |
| T-70-37 | Spoofing | host-admin credential comparison | high | mitigate | Use Plug.BasicAuth's constant-time comparison with no query/cookie/header-derived actor or organization fields and deny missing configuration. |
| T-70-38 | Information disclosure | Basic credential over approved local HTTP | high | mitigate | Traefik binds public ingress to 127.0.0.1, the harness generates an ephemeral password, and Playwright adds the header only after returning to the relyra.localhost admin path. |
| T-70-39 | Information disclosure | E2E logs and retained diagnostics | high | mitigate | Keep browser attachments disabled, add the admin credential to the production redactor and fail-closed sentinel self-test, and never print environment values. |
| T-70-40 | Repudiation | browser trust evidence | medium | mitigate | Preserve one correlation-specific Login Trace containing the canonical validation/signature/replay steps after the authenticated transition. |
</threat_model>
