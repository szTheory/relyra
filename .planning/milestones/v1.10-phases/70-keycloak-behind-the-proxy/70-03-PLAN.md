<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| environment input → Compose/realm public URLs | One hostname value controls two origins and all SAML endpoints. |
| Docker management network → Traefik | Internal application/readiness ports must not become public routes. |
| failed containers/audit → retained diagnostics | Operational evidence may contain authentication material unless redacted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-70-10 | Spoofing | Mixed public/internal hostname | high | mitigate | Dual render checks and live public descriptor assertions from one RELYRA_HOST input. |
| T-70-11 | Information disclosure | Keycloak management interface | high | mitigate | No host port, no 9000 Traefik service, region-scoped rendered-config negative assertions. |
| T-70-12 | Tampering | Existing realm import | high | mitigate | Harness-owned realm-state recreation and post-start descriptor/client contract probes. |
| T-70-13 | Information disclosure | Failure artifacts | high | mitigate | Redactor self-test and allowlisted status/action diagnostics only. |
| T-70-14 | Denial of service | Shared proxy teardown | medium | mitigate | Ownership markers and conditional cleanup inherited from the Phase 69 harness. |
</threat_model>
