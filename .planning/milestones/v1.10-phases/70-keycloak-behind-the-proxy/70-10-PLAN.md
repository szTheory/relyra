<objective>
Close the remaining Phase 70 blocker by making retained-diagnostic XML enforcement namespace-aware, document-stateful, and adversarially proven; also lock the already fail-closed missing-admin-configuration behavior with direct route coverage.

Purpose: The current redactor and promotion validator match only unprefixed protected tags. A normal multiline `samlp:Response` can therefore retain nested assertion values in artifacts labeled safe, violating D-26 and blocking KC-01.
Output: A production-quality shell policy that redacts complete qualified SAML/metadata documents, an independent validator that refuses unsafe promotion, a multiline nested sentinel regression, and focused missing/partial host-admin denial tests.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted container/browser output -> diagnostic staging | Docker, Keycloak, Phoenix, and browser failures may contain credentials, signed SAML, descriptor XML, PEM, cookies, authorization values, or database URLs before shell redaction. |
| staged diagnostic files -> promoted retained artifacts | `validate_diagnostic_tree` is the last independent gate before three text files become durable operator-visible output. |
| runtime host-admin configuration -> demo admin scope | Both configured credential values must exist and authenticate before either the bootstrap route or mounted LiveAdmin routes can establish the fixed scope. |

## STRIDE Threat Register — ASVS L1, block high

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-70-46 | Information disclosure | `redact_diagnostics` qualified XML handling | high | mitigate | Match protected XML by exact local name with an optional valid QName prefix, maintain document state across lines, and adversarially prove nested tag/attribute/value sentinels never survive. |
| T-70-47 | Tampering | `validate_diagnostic_tree` / `promote_diagnostics` | high | mitigate | Independently reject namespace-qualified protected tags in staging and prove a deliberately raw tree is discarded rather than promoted. |
| T-70-48 | Denial of service | malformed or unterminated protected XML in logs | low | accept | Fail closed by suppressing the remainder of the affected input; diagnostic completeness is less important than retaining partial assertion or descriptor content. |
| T-70-49 | Elevation of privilege | absent/partial `:demo_admin_auth` runtime config | high | mitigate | Exercise both guarded route families across missing-key and empty-value configurations and assert 401, Basic challenge, and zero scope session keys. |
| T-70-50 | Repudiation | diagnostic policy self-test coverage | medium | mitigate | Use fixed named sentinels and exact promoted-tree assertions so CI evidence identifies the qualified XML disclosure class and fails deterministically on regression. |
</threat_model>
