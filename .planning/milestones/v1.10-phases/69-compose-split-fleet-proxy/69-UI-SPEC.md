# Phase 69 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Phase Scope and Interaction Contract

This is an infrastructure-only phase. It changes Docker Compose ingress and Phoenix endpoint/origin configuration; it introduces no page, component, route, browser control, banner, modal, or user-facing copy. Preserve the existing LedgerLoop browser UI unchanged.

The observable contract is access-path equivalence:

- **Solo:** `docker compose up` serves the unchanged demo at `http://localhost:${PORT:-4000}`. Only this path publishes the loopback app port; PostgreSQL is never host-published.
- **Fleet:** the explicit base + proxy overlay serves the unchanged demo at `http://${RELYRA_HOST:-relyra.localhost}` through Traefik. It publishes no app or database port and must not depend on the automatic solo override.
- **LiveView:** both public hosts are present in the explicit `check_origin` allowlist, so the existing operator UI's WebSocket connection succeeds without a browser-visible workaround.
- **Out of scope:** Keycloak proxy UX, launcher URL banners, diagnostics, and documentation are Phase 70–72 work. Do not add them here.
