# Roadmap: Relyra v0.6

## Milestone

**v0.6 — Operational maturity carryover + SLO**  
Shipped 2026-05-08.

## Scope

This milestone closed the operational carryovers deferred from v0.5 and completed the remaining SAML logout surface before the v1.0 conformance and external-review work.

Requirements:
- `CERT-EXP-01`
- `DIAG-01`
- `SLO-01`

## Phases

- [x] **Phase 22: Certificate Expiry Alerts** — System emits events and logs for upcoming SAML signing certificate expirations without imposing a scheduler on adopters.
- [x] **Phase 23: Diagnostic Bundles** — Operators can export a redacted troubleshooting bundle with strict allow-list shaping.
- [x] **Phase 24: Single Logout Protocol (SLO)** — SP-initiated and IdP-initiated logout flows are implemented with strict validation and correlation handling.

## Phase Details

### Phase 22: Certificate Expiry Alerts
**Goal**: Operators receive timely alerts before SAML certificates expire, allowing proactive rollover.  
**Depends on**: Phase 21  
**Requirements**: `CERT-EXP-01`  
**Plans**: 1/1 complete

### Phase 23: Diagnostic Bundles
**Goal**: Operators can securely export a troubleshooting bundle without leaking secrets or PII.  
**Depends on**: Phase 22  
**Requirements**: `DIAG-01`  
**Plans**: 2/2 complete

### Phase 24: Single Logout Protocol (SLO)
**Goal**: Users can safely log out of both the Service Provider and Identity Provider in one verified flow.  
**Depends on**: Phase 23  
**Requirements**: `SLO-01`  
**Plans**: 3/3 complete
