# Requirements: Relyra v0.6

**Defined:** 2026-05-07
**Milestone:** v0.6 — Operational maturity carryover + SLO
**Core Value:** Every SAML login ends in a verified trust path or a typed rejection — never a silent compromise.

## v0.6 Requirements

Committed scope for v0.6 includes deferred items from v0.5 (debug bundles, expiry alerts) and the introduction of Single Logout (SLO).

### Operational Maturity (v0.6)

- **DIAG-01**: Operator can generate a redacted debug bundle for troubleshooting.
- **CERT-EXP-01**: User can receive operator-facing alerts (events + log entries) for upcoming SAML signing certificate expirations, configurable per connection, with thresholds aligned to the staged-rollover cadence.

### Protocol Surface (v0.6)

- **SLO-01**: User can complete standards-compliant Single Logout flows.
