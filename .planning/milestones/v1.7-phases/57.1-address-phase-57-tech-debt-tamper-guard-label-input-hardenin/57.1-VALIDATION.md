## Sampling Rate

- **After every task commit:** Run the single affected test file via `mix --cd demo/ledger_loop test <file>` (or root `mix test <file>` for `poll.ex`).
- **After every plan wave:** Run `mix ci.demo_app` + `mix test --warnings-as-errors` (root).
- **Before `/gsd:verify-work`:** `mix qa` exits 0 (no unstaged format diff), `mix ci.security` green, `mix ci.demo_app` green.
- **Max feedback latency:** < 60 seconds (single-file quick run).
