<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| adopter test -> `Relyra.Testing` | Untrusted caller options become SAML XML fixture fields and connection/request data. |
| fixture XML -> `Relyra.consume_response/3` | Public generated XML crosses into the real parser, signature, digest, and validation pipeline. |
| fixture cert -> verifier trust material | Returned cert chain becomes explicit test trust input; document `KeyInfo` remains untrusted. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T64-01 | Spoofing/Tampering | `Relyra.Testing.Signer.signed_response/1` | mitigate | Compute real `DigestValue` and `SignatureValue`; prove `signed_success/1` succeeds through `Relyra.consume_response/3`. |
| T64-02 | Spoofing | `Relyra.Testing.signed_success/1` | mitigate | Return cert chain in fixture `connection`, `cert_chain`, and `idp_certificates`; assert response XML contains no `<KeyInfo>`. |
| T64-03 | Tampering | `Relyra.Testing.Signer` | mitigate | Use `SaxyTree`, `PureBeam.canonicalize/1`, and `C14N.serialize/1`; forbid alternate XML parser or fixture-only C14N. |
| T64-05 | Elevation of Privilege | `Relyra.Testing.consume_opts/2` | mitigate | Thread trust through explicit opts and fixture data only; no Application env, persistent global trust, or production resolver mutation. |
</threat_model>
