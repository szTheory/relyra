    Create `.planning/phases/45-post-publish-parity-verification/verify-parity.sh`:

    ```bash
    #!/usr/bin/env bash
    set -euo pipefail
    ROOT="$(cd "$(dirname "$0")/../../.." && pwd)"
    cd "$ROOT"
    PHASE_DIR=".planning/phases/45-post-publish-parity-verification"
    VERSION="1.4.0"
    RESULT="$PHASE_DIR/PARITY-RESULT.md"
    LOG="$(mktemp)"

    git fetch --tags

    set +e
    mix verify.release_parity "$VERSION" 2>&1 | tee "$LOG"
    PARITY_EXIT=$?
    set -e

    # Collect metadata (best-effort; do not mask PARITY_EXIT)
    HEX_CHECKSUM=$(curl -fsS "https://hex.pm/api/packages/hexpm/releases/relyra/${VERSION}" | rg '"checksum":"([^"]+)"' -or '$1' || echo "unavailable")

    git checkout "v${VERSION}" --quiet 2>/dev/null || true
    mix hex.build --unpack 2>/dev/null || true
    LOCAL_TAR="relyra-${VERSION}.tar"
    LOCAL_CHECKSUM=$(test -f "$LOCAL_TAR" && shasum -a 256 "$LOCAL_TAR" | awk '{print $1}' || echo "unavailable")
    git checkout - --quiet 2>/dev/null || true

    mix hex.audit > "${LOG}.audit" 2>&1 || true
    mix ci.release > "${LOG}.release" 2>&1 || true

  # Write PARITY-RESULT.md (see Task 2 for full template)
    exit "$PARITY_EXIT"
    ```

    **Requirements:**
    - `chmod +x` the script.
    - Script must `exit` with the same code as `mix verify.release_parity` (0/2/1).
    - Do not hard-code **PASS** — derive verdict from `PARITY_EXIT`.
    - Use repo root relative to script (`../../..` from phase dir).

    Extend script to write `PARITY-RESULT.md` (can be same task or follow-on in Task 2).
  </action>
