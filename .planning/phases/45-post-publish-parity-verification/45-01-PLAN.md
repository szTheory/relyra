    Create `lib/mix/tasks/verify.release_parity.ex` with:

    1. **Module:** `Mix.Tasks.Verify.ReleaseParity`, `@shortdoc "Compare Hex tarball paths to git tag for a released version"`.

    2. **Public API (testable):**
       - `compute/2` — copy scrypath MapSet diff (`:parity` | `{:drift, only_git, only_hex}`).
       - `parse_version!/1` — semver regex `~r/^\d+\.\d+\.\d+([.-][A-Za-z0-9.-]+)?$/`; reject `v` prefix and shell metacharacters.
       - `retry_until!/4` — same semantics as scrypath; env `RELYRA_RELEASE_VERIFY_ATTEMPTS` (default 10), `RELYRA_RELEASE_VERIFY_SLEEP_MS` (default 15000).
       - `render_json/4` — Jason-encoded `%{"version" => _, "status" => "ok"|"drift", "only_in_git" => _, "only_in_hex" => _}`.
       - `expected_relative_paths/0` — returns sorted list of path **prefixes and root files** matching `mix.exs` `package.files`:
         - Directory prefixes: `lib/`, `priv/`, `docs/`, `guides/`
         - Root files: `.formatter.exs`, `mix.exs`, `README.md`, `CONFORMANCE.md`, `CHANGELOG.md`, `LICENSE`, `SECURITY.md`, `SECURITY_REVIEW.md`, `SECURITY_REVIEW_EVIDENCE.md`, `BATTERIES_INCLUDED.md`
         - Filter rule: include path if it starts with any directory prefix OR equals a root file; **exclude** any path containing `test_support`.
       - `filter_package_paths/1` — apply rules above to a list of relative paths.
       - `assert_no_test_support!/1` — if any path contains `"test_support"`, print message and `System.halt(2)`.

    3. **`run/1` flow:**
       - `Mix.Task.run("app.start")` (not required for git/hex subprocess but harmless).
       - Parse `argv` for version + optional `--json`.
       - `tmp_root = Path.join(System.tmp_dir!(), "relyra-release-parity-#{System.unique_integer([:positive])}")`.
       - Fetch hex: `mix hex.package fetch relyra VERSION --unpack -o tmp_root` inside `retry_until!/4`.
       - Collect hex paths: `Path.wildcard(Path.join(tmp_root, "**/*")) |> Enum.filter(&File.regular?/1) |> Enum.map(&Path.relative_to(&1, tmp_root)) |> filter_package_paths/1`; drop `hex_metadata.config` if present.
       - `assert_no_test_support!/1` on raw hex paths **before** diff.
       - Fetch git: `git ls-tree -r --name-only v{VERSION}` (tag `v` + version), filter with `filter_package_paths/1`.
       - `compute(git_set, hex_set)` → emit parity or drift; drift → `System.halt(2)`; rescue cleanup `File.rm_rf(tmp_root)` in `after`.

    4. **Moduledoc** must state: path-set gate (not outer tar SHA256), exit codes 0/2/1, env retry vars, tag format `vX.Y.Z`.

    5. **Do NOT** add `mix hex.publish`, modify `package.files`, or wire CI in this plan.
