<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| descriptor bytes → audited Ecto trust state | Generated Keycloak certificate and endpoints become configured authentication inputs. |
| provision retry/rotation → enabled resolver snapshot | Partial or stale state must never become login-ready. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-70-06 | Tampering | Key regeneration/reconciliation | high | mitigate | Disable-before-change, descriptor fingerprint comparison, audited activation, and resolver-snapshot rotation tests. |
| T-70-07 | Repudiation | Idempotent provisioning | high | mitigate | Actor/cause/correlation assertions plus unchanged-run audit-count equality. |
| T-70-08 | Elevation of privilege | Host SAMLIdentity mapping | high | mitigate | Exact Sarah subject + public issuer unique identity; no admin persona and no fallback mapper behavior. |
| T-70-09 | Denial of service | Failed reconciliation | medium | mitigate | Fail closed with retryable layer error and a disabled/draft connection; no partial enable. |
</threat_model>
