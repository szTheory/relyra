## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser → Traefik → Keycloak/LedgerLoop | Public host and forwarded headers cross the only browser ingress. |
| keycloak_provisioner → Keycloak descriptor | Container-local XML enters durable trust configuration. |
| Keycloak ACS POST → Relyra verifier | Untrusted SAMLResponse crosses existing raw-binary guards, Saxy parse, digest, signature, protocol, and replay gates. |
