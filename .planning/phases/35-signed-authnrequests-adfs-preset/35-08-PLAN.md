## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CI alias execution → suite gating | A line in `mix.exs` `ci.security` is the ONLY thing that runs a security suite on CI. A missing/malformed/deduped line silently skips the suite. The meta-gate (`ci_gate_integrity_test.exs`) is the trust boundary that asserts every named suite is actually executed. |
| Suite source `@moduletag` → `--only <tag>` filter | The `--only authn_request_signing` flag matches ZERO tests if the suite source does not declare `@moduletag :authn_request_signing` exactly. Zero-match means hollow gate. The tag-integrity test at `ci_gate_integrity_test.exs:136-149` asserts the atom exists in source. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-35-06 | Tampering | `mix.exs` `ci.security` alias + `test/security/ci_gate_integrity_test.exs` `@gated_suites` | mitigate | This plan IS the mitigation. The meta-gate's four assertions (file-exists, alias-references-suite, `cmd mix test` shape, `--only <tag>` tag-integrity) make EVERY future tamper attempt visible: if anyone collapses the new `cmd mix test` line into a bare `test`, drops it, swaps the suite path for a typo, renames the tag, or removes the `@gated_suites` tuple, the meta-gate fires and the build goes red. Note: the meta-gate cannot detect tampering of the meta-gate itself (someone deleting the `@gated_suites` entry), but `ci_gate_integrity_test.exs` is itself in `@gated_suites` AND runs as its own `cmd mix test` step (line 167) — so any change to its source is at least picked up by `mix compile --warnings-as-errors`, and removing entries from `@gated_suites` removes assertions but does not cause silent FAILURE of remaining ones. The structural reduction means tampering must be deliberate + multi-file (mix.exs AND ci_gate_integrity_test.exs) AND defeat code review — a meaningfully harder bar than the Phase 30 hollow-gate bug it was designed to prevent. |
