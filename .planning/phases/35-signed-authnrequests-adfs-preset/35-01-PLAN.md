## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → `sign_redirect_query/3` | Octets binary crosses untrusted (operator-controlled `idp_sso_url`/`RelayState`) into the SP crypto seam; signing key crosses from `Application.get_env` (trusted boot config) |
| `sign_redirect_query/3` → `:public_key.sign/3` | Raw octets MUST flow verbatim — re-encoding here is the auth-bypass class (T-35-01) |
| filesystem → committed PEM | Generated once, committed, never re-minted without PROVENANCE.md update |

| T-35-02 | Information Disclosure | `:sp_signing_key_pem` Application config + `Error.t()` `:details` map | mitigate | D-06: Application-env-only seam (mirrors `KeyResolver.Default`); D-07: typed `:key_not_configured` never includes key bytes; `details` map carries only `connection_id` + `signature_method` + `hint` text |
