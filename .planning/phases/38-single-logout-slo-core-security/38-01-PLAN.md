<objective>
Introduce foundational contracts for Session decoupling and HTTP-Redirect signature verification to enable secure SLO.

Purpose: 
To implement SLO properly, Relyra must allow the host application to track sessions by `SessionIndex`. In addition, HTTP-Redirect bindings sign the raw URL query string (unlike HTTP-POST which uses XMLDSig). We must introduce a secure method for verifying these raw octets before implementing the rest of the flow.
Output: Extended `SessionAdapter` and `Signature` modules.
</objective>
