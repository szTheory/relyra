## Decisions Made

- **Runtime introspection via `Relyra.SessionAdapter.behaviour_info(:callbacks)`** (D-05): Map callback names to arities at runtime; never write a literal `arity == 4` assertion. The test follows whatever the behaviour says — if `SessionAdapter` callbacks evolve, the test self-updates without source edits.
- **`@tag :skip` in Wave 1** (D-12 land-test-first-then-unskip): The test scaffold lands now (test code + ci.docs wiring), but the assertion is gated by `@tag :skip` because `guides/recipes/logout.md` lines 107/121 still have the wrong signatures until Plan 40.1-05 rewrites them. Plan 40.1-05 removes `@tag :skip` in the same commit as the doc rewrite — flipping the gate live atomically.
- **Dedicated `cmd mix test` line** (D-06 Phase 30 hollow-gate invariant): Each drift test runs as its own OS process. CLAUDE.md "Testing Requirements" calls this out as non-negotiable — Mix dedups the `test` task within a single alias run, so a bare `test` step would be silently skipped.
- **Placement immediately after the troubleshooting drift line**: Groups the two drift tests for chronological clarity (troubleshooting first, then logout_recipe) and easy `grep -n 'drift_test' mix.exs`.
- **No moduledoc-level `4` literals**: Even in prose, avoided the digit `4` to keep the file `grep`-clean against the no-hardcoded-arity discipline. Used "the four-arg signature" → "the canonical arity" wording where applicable.
