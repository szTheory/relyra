# Phase 40.1 Plan 05: Logout Recipe SessionAdapter Signature Rewrite + Drift Gate Unskip Summary

Rewrote `guides/recipes/logout.md`'s SessionAdapter code example from the broken `(connection, login_result, local_session_id, opts)` / `(connection, session_index, _name_id, _opts)` shape to the canonical 4-arg `(session_index, issuer, context, _opts)` shape from `lib/relyra/session_adapter.ex:19-31`, added a new "Host-owned linkage" H3 subsection documenting that hosts must invoke `index_session/4` from their ACS controller (Relyra does NOT auto-invoke it), and in the same commit removed the `@tag :skip` from the Plan 03 drift test — closing BLOCKER 1 and WARNING 2 from v1.4-MILESTONE-AUDIT.md and flipping the drift gate live.

## What Changed

### Task 1: Rewrote `guides/recipes/logout.md` section 3 area

Three coupled edits, all within lines 91-145 (sections 1, 2, 4 byte-untouched per D-04):

1. **Narrative at lines 97-99 (Change A)** — Replaced the misleading sentence "Relyra extracts this and passes it to your adapter" with prose accurately reflecting the host-owned-linkage policy: Relyra surfaces `SessionIndex` at `login_result.principal.session_index` on the `%Relyra.LoginResult{}` returned from `Relyra.consume_response/3`; the host is responsible for invoking `index_session/4`.

2. **Code block at lines 100-127 (Change B)** — Replaced the entire fenced `elixir` block with a new example using the canonical 4-arg signatures. Both `def index_session(session_index, issuer, context, _opts)` and `def terminate_by_session_index(session_index, issuer, context, _opts)` now match `lib/relyra/session_adapter.ex:19-31` callbacks verbatim. Bodies illustrate realistic host-side store invocations (`SessionStore.map_saml_index/4`, `SessionStore.delete_by_saml_index/3`) and return `{:ok, _} | {:error, Relyra.Error.t()}` shapes per the typespec.

3. **New H3 subsection between sections 3 and 4 (Change C)** — Inserted `### Host-owned linkage (you must invoke index_session/4 yourself)` containing 7 lines of operator-facing prose. Explicitly contrasts the host-owned path (index, no inbound trigger, depends on host-only `local_session_id`) with the auto-wired path (terminate, fully derivable from inbound `LogoutRequest`).

Result: line count grew from 155 to 180 (+25 lines, as predicted by the plan ~10-15 estimate plus blank-line separators). Sections 1, 2, 4 confirmed byte-untouched via `git diff -U0` hunk-bounds inspection.
