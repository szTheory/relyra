| connection update path -> certificate inventory | association replacement could silently delete active or staged trust rows |

| T-10-02-02 | E | `lib/relyra/ecto/connection.ex` | mitigate | Return an explicit boundary error or rejection message when callers try to manage certificates through the wrong API surface. |
| T-10-02-03 | D | `lib/relyra/ecto/connection.ex` | mitigate | Preserve existing certificate rows during ordinary connection edits so routine config updates cannot self-inflict trust outages. |
</threat_model>
