<objective>
Build the internal persistence shape for Phase 07: the normalized
connection aggregate root, minimal child certificate inventory, canonical
in-repo migrations, and the real-Repo constraint tests that prove the
tables, indexes, and foreign keys behave as planned.
</objective>

<threat_model>
  <threat id="TM-07-02-PUBLIC-ID-DRIFT" severity="high">
    If `connection_id` is not enforced as immutable and globally unique,
    later resolver and route behavior can target the wrong trust record.
  </threat>
  <threat id="TM-07-02-REPLACE-IN-PLACE-TRUST" severity="high">
    If trust material lands on the parent row instead of a child table,
    Phase 10 rollover will require a schema rewrite.
  </threat>
  <mitigations>
    - Use internal `:binary_id` PKs and a public `connection_id`
      generated/validated as `Ecto.ULID`.
    - Keep certificates as additive child rows with provenance/fingerprint
      metadata and FK-backed deletion.
    - Use real migration tests to prove the DB constraints instead of
      assuming them from changeset code.
  </mitigations>
  <verification_commands>
    - `test -f lib/relyra/ecto/connection.ex`
    - `test -f lib/relyra/ecto/certificate.ex`
    - `test -f priv/repo/migrations/*_create_relyra_connections.exs`
    - `test -f priv/repo/migrations/*_create_relyra_connection_certificates.exs`
    - `mix test test/relyra/ecto/migration_constraints_test.exs test/relyra/ecto/connection_schema_test.exs test/relyra/ecto/certificate_schema_test.exs --warnings-as-errors`
  </verification_commands>
</threat_model>
