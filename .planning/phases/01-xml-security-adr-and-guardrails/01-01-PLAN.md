<objective>
Lock the XML security architecture decision in a single ADR before any protocol implementation, including an explicit pure-BEAM default locked to `saxy`, a hybrid/xmlsec fallback trigger, and a conditional NIF supply-chain policy.
</objective>

<threat_model>
  <threat id="TM-01-ADR-DRIFT" severity="high">
    Ambiguous strategy language allows downstream code to mix parser paths and bypass a single trust boundary.
  </threat>
  <threat id="TM-01-NIF-POLICY-GAP" severity="high">
    If the project pivots to NIF/hybrid later without pre-locked matrix and checksum policy, release artifacts can ship without supply-chain controls.
  </threat>
  <mitigations>
    - ADR states one selected strategy (`pure-beam single parser (saxy)`) and one fallback trigger sentence verbatim.
    - ADR includes an explicit conditional NIF matrix and checksum verification section with concrete target triples.
    - Phase 1 roadmap section references the ADR path as the canonical decision record.
  </mitigations>
