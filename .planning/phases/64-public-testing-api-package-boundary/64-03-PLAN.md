## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `Relyra.Testing.Phoenix` -> host endpoint | Public helper sends SAML POST params into a caller-supplied Phoenix endpoint and route. |
| ACS route -> verifier | ACS decodes POST params and invokes `Relyra.consume_response/3`. |
| core testing modules -> non-Phoenix consumers | Core package files must compile and be readable without Phoenix-specific helper use. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T64-01 | Spoofing/Tampering | Phoenix helper success path | mitigate | Test helper posts a real signed fixture to ACS, which then reaches `consume_response/3`. |
| T64-05 | Elevation of Privilege | `Relyra.Testing.Phoenix.post_response/5` | mitigate | Helper dispatches only; it does not assign sessions, establish users, or mutate trust. |
| T64-06 | Denial of Service | core `Relyra.Testing` modules | mitigate | Source guard prevents Phoenix/Plug.Conn references in core fixture files; Phoenix dispatch lives in `Relyra.Testing.Phoenix`. |
</threat_model>
