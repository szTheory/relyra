## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Diagnostic Export | Raw Ecto structs are transformed into external JSON payload |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-23-01 | Information Disclosure | `allow_list.ex` | mitigate | Use pure Elixir maps for extraction (deny-by-default); do not use `@derive Jason.Encoder` on Ecto structs. |
| T-23-02 | Denial of Service | `diagnostic.ex` | mitigate | Bound the audit log query to max 1,000 recent events to prevent `:memory` zip generation from exhausting BEAM memory. |
| T-23-03 | Information Disclosure | `allow_list.ex` | mitigate | Hash `correlation_id` in audit logs using `:crypto.hash(:sha256, id)` to prevent PII leakage. |
</threat_model>
