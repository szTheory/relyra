Extend the `SessionAdapter` to support IdP-initiated session revocation, and update `RequestStore` to ensure intent isolation between Authentication and Logout flows.

Purpose: Allows host applications to respond to IdP-initiated logouts by destroying the user session, and prevents an SP-initiated `<LogoutResponse>` from being reused as an `<AuthnResponse>`.
Output: Updated core behaviours for session and request management.
</objective>
