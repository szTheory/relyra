<objective>
Build the hand-rolled exclusive XML Canonicalization 1.0 (no-comments) engine that serializes a
SaxyTree node (shape defined in Plan 01) to byte-exact canonical UTF-8 — the only net-new algorithm
in this phase, with NO in-repo analog. Hand-rolling is mandated by D-05 (no correct exclusive-C14N
BEAM library exists — esaml/xmerl_c14n is inclusive-only + carries CVE-2026-28809 XXE). It implements
the full correctness surface required by D-06:
visibly-utilized namespace rendering against a rendered-vs-in-scope stack pair, PrefixList forced
rendering, the exact sort order (ns by local name; attrs by resolved URI then local name), the two
escaping functions, empty-element expansion, no trailing newline, and the enveloped-signature
transform that prunes the specific `ds:Signature` subtree before serialization.

Purpose: This is the canonical-bytes precondition for Phase 29's `:public_key.verify` and
DigestValue recompute (SIGV-03, ROADMAP success #2). A single byte-divergence here silently defeats
the downstream digest check and re-opens the confirmed SAML auth-bypass class — so correctness must
later be PROVEN against an independent golden oracle (Plan 04, D-11/D-12), not self-asserted here.
Output: `lib/relyra/security/xml/c14n.ex`.

Note: this engine is exercised by self-checks (idempotence, structural assertions) in this plan; the
authoritative byte-equality proof against the independent reference lands in Plan 04.
</objective>
