<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Checkout to unpacked artifact | Package whitelist decides what a downstream developer can receive. |
| Artifact to temporary consumer | Dependency resolution must not fall back to checkout source or private tests. |
| Signed SAML POST to ACS | Untrusted XML reaches the existing verifier through Phoenix. |
| Harness to PostgreSQL and logs | State and potentially sensitive output cross process boundaries. |

| T-74-02 | Elevation of privilege | ACS success path | high | mitigate | Task 1 posts a public signed fixture through the real ACS controller and checks a host callback reached only after verified consume. |
