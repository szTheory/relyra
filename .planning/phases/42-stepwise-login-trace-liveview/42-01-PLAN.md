    Create `lib/relyra/telemetry/handlers/login_trace.ex` with:

    - `@handler_id :relyra_login_trace`
    - `attach(repo:)` / `detach/0` using `:telemetry.attach_many/4`
    - Events: `[:relyra, :saml, :response, :consume, :start|:stop|:exception]` plus six child `:stop` events for `[:response, :decode]`, `[:response, :validate]`, `[:signature, :verify]`, `[:replay, :check]`, `[:user, :map]`, `[:session, :establish]`
    - On `:consume, :start`: `Process.put(:relyra_login_trace, %{repo: repo, steps: %{}, connection_id: metadata[:connection_id], correlation_id: metadata[:correlation_id], flow: metadata[:flow]})` — generate `correlation_id` with `Ecto.UUID.generate()` when absent
    - On each child `:stop`: merge step keyed by string name (e.g. `"response.decode"`) with `outcome`, `error_code`, `duration_ms` from measurements/metadata (drop sensitive keys)
    - On `:consume, :stop` or `:exception`: build attrs `%{domain: :login, action: :succeeded | :failed, actor: "system:login_trace", cause: flow string, correlation_id: ..., after_summary: %{"steps" => steps, "overall_outcome" => ...}, before_summary: %{}, diff_summary: %{}}`, resolve `connection_record_id` from `connection_id` via repo lookup (skip append if connection not found), call `AuditWriter.append_event(repo, attrs)`, set `Process.put(:relyra_validation_trace, steps_as_list)`, clear `:relyra_login_trace`
    - Store `repo` in handler config (4th attach arg), not Process dict alone

    Step list order for `validation_trace`: fixed order matching CONTEXT D-08 (six steps).
  </action>
