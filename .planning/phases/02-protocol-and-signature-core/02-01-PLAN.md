<objective>
Implement the SP-initiated request primitives for Phase 2 by adding deterministic AuthnRequest generation, transport binding helpers, and an opaque RelayState contract rooted in `rs_` handles so core protocol code never accepts raw redirect URLs.
</objective>

<threat_model>
  <threat id="TM-02-01-OPEN-REDIRECT" severity="high">
    Accepting URL-shaped RelayState values enables open-redirect and trust confusion before response validation runs.
  </threat>
  <threat id="TM-02-01-REQUEST-FORMAT-DRIFT" severity="medium">
    Inconsistent AuthnRequest field generation (missing destination/issuer/binding values) causes protocol interop drift and non-deterministic downstream failures.
  </threat>
  <mitigations>
    - Define `Relyra.Security.RelayState.issue/2` and `Relyra.Security.RelayState.validate/2` with strict `rs_` token format and explicit `:relay_state_rejected` typed failures for URL/tamper patterns.
    - Build AuthnRequest payloads from one internal module (`Relyra.Protocol.AuthnRequest.build/3`) with concrete required keys and stable ID prefix `id_`.
    - Keep all outputs typed as `{:ok, value}` or `{:error, %Relyra.Error{}}` through `Relyra.start_login/3`.
    - High-severity threats in this plan are blocking; do not mark the plan complete until all verification commands pass.
  </mitigations>
  <verification_commands>
    - `rg -n "def start_login\\(connection, relay_context, opts \\\\ \\[\\]\\)" lib/relyra.ex`
    - `rg -n "def build\\(connection, relay_context, opts \\\\ \\[\\]\\)|\"id_\"|issue_instant|protocol_binding" lib/relyra/protocol/authn_request.ex`
    - `rg -n "def issue\\(relay_context, opts \\\\ \\[\\]\\)|def validate\\(relay_state, opts \\\\ \\[\\]\\)|:relay_state_rejected|rs_" lib/relyra/security/relay_state.ex`
    - `mix test test/protocol/authn_request_test.exs --warnings-as-errors`
    - `mix test test/protocol/relay_state_test.exs --warnings-as-errors`
  </verification_commands>
</threat_model>

  - RelayState handling is opaque (`rs_` handles only), storage-agnostic, and rejects raw URL redirects by default.
  - Every public failure path in this plan returns `%Relyra.Error{}` with stable typed atoms (`:relay_state_rejected`, `:invalid_binding_payload`) and no silent success behavior.
</must_haves>
