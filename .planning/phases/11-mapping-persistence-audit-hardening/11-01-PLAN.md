<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| host app config input -> Ecto schemas | Untrusted mapping and audit attributes enter trust-bearing persistence contracts |
| parent connection changeset -> child mapping associations | Generic aggregate updates could bypass audited mapping mutation rules if not blocked |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-01-01 | T | `Relyra.Ecto.Connection` generic changesets | mitigate | Mirror the certificate rejection pattern and reject mapping association writes in parent changesets so authoritative mapping writes stay on dedicated commands per D-10. |
| T-11-01-02 | I | `Relyra.Ecto.AuditEvent` payload fields | mitigate | Restrict audit payloads to normalized bounded maps and exclude raw XML, PEM, and unbounded request payloads per D-14 and D-15. |
| T-11-01-03 | R | mapping and audit ledgers | mitigate | Use append-only schemas with explicit actor, cause, correlation, before, after, and diff fields per D-03 and D-20. |
</threat_model>
