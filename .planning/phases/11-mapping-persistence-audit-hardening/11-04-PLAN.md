<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| operator-supplied mapping definitions -> mapping command surface | Untrusted mapping config enters trust-bearing persistence logic |
| persisted mapping rows -> runtime snapshot | Stored data crosses into login-time runtime mapping decisions |
| runtime mapping_config -> default user mapper | User identity shaping consumes hydrated rules |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-04-01 | T | `Relyra.Ecto.MappingCommands` | mitigate | Restrict writes to dedicated command functions with enum-backed explicit semantics, in-transaction revision writes, and cross-domain audit writes. |
| T-11-04-02 | R | mapping revision and audit history | mitigate | Record actor, cause, optional correlation id, and normalized before/after/diff summaries for every mapping mutation per D-03 and D-20. |
| T-11-04-03 | I | runtime hydration boundary | mitigate | Collapse rows into plain `mapping_config` maps only and reject malformed persisted rows before they reach `Relyra.UserMapper` per D-04. |
| T-11-04-04 | E | multivalue and group-match semantics | mitigate | Allow only exact source matches and bounded `:first` / `:all` multivalue behavior, with no regex or expression evaluation path per D-08 and D-09. |
</threat_model>
