<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| macOS host → Linux container (runtime bind mount) | Host source is bind-mounted at `.:/app`; the `relyra_*` named volumes mask the compiled-artifact subpaths so host (ARM/macOS) binaries never enter the container's deps/_build. |
| Docker-managed volume state | The `relyra_build` volume holds the lock-hash stamp and compiled `_build`; dev-only, wiped by `docker volume rm`. |

NOTE: This plan changes NO `lib/` crypto, parse, replay, audit, auth, or protocol code (milestone invariant). It wires Docker dev tooling only. Relyra's verification seams are untouched (exercised by the running demo, not modified).

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-68-05 | Tampering | Host-compiled artifacts leaking into the container (arch/NIF corruption) | mitigate | Named volumes attach at the exact nested paths `/app/demo/ledger_loop/deps` and `/app/demo/ledger_loop/_build` (D-04), masking the bind mount so macOS binaries never reach the Linux runtime. Acceptance criteria assert the nested paths and forbid generic `/app/deps`. |
| T-68-06 | Information Disclosure | Dev secrets in compose env (`POSTGRES_PASSWORD`, `secret_key_base`) | accept | Pre-existing, dev-only, not introduced or worsened here; D-05 leaves the `environment:` block unchanged. No production exposure. |
| T-68-07 | Denial of Service | `:fs_poll` idle CPU from 500ms polling | accept | Negligible idle CPU on dev hardware; polling is the ONLY backend that works across the macOS→Docker mount (RESEARCH §Alternatives). Native `mix phx.server` outside Docker polls instead of inotify — minor idle CPU only (D-10 evidence). |

No high-severity threats present. This plan is dev/demo Docker wiring with no trust-boundary, crypto, auth, or `lib/` change; the most security-relevant control is the named-volume masking (T-68-05) that prevents host-artifact contamination, enforced as Task 1 acceptance criteria.
