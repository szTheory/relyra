<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Seed constants -> database | Fixture constants become persistent host-owned demo rows. |
| Demo reset -> existing database | Reset deletes/replaces only the seeded demo scope. |
| Host identity rows -> later Relyra mapper | SAML identity linkage will be used by host-owned mapping after Relyra verification. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-52-01 | Information disclosure | `LedgerLoop.Demo.Fixtures` | mitigate | Use display-safe emails, slugs, group keys, and fixed timestamps; do not include raw XML, private keys, or secrets in host fixtures. |
| T-52-02 | Tampering | `LedgerLoop.Demo.Reset.reset!/0` | mitigate | Delete by stable seeded scope and reinsert fixed IDs so unrelated local data is not removed. |
| T-52-03 | Spoofing | SAML identity linkage rows | mitigate | Store linkage only as host-owned lookup data; Plan 52-05 maps it only after Relyra returns a verified principal. |
| T-52-04 | Tampering / Elevation of privilege | request-derived table selection | transfer | Plan 52-04 owns fixed request/replay wrapper mitigation. |
| T-52-05 | Spoofing | replay acceptance | transfer | Plan 52-04 and Plan 52-06 own Ecto replay storage proof. |
| T-52-06 | Tampering | parser bypass | mitigate | This plan adds no XML parser and does not inspect SAML payloads. |
| T-52-SC | Tampering | package installs | accept | No package-manager installs are planned. |
</threat_model>
