Extend `AlgorithmPolicy` with two new public enforcement functions and three new struct fields
covering XML-Enc key-transport and content-encryption algorithm policy (ENC-03).

functions existing first. RSA-PKCS1v1.5 must be permanently blocked with no escape hatch;
AES-CBC must be blocked by default with a time-boxed override; truncated GCM auth tags must
be rejected before `:crypto.crypto_one_time_aead/7` is ever called.

Output: Extended `algorithm_policy.ex` (struct + 2 functions), expanded test coverage in
`algorithm_policy_test.exs`, and two new proof assertions in `strict_default_proof_test.exs`.
