The logotype must be unified with the mark (not icon-left-of-text), the primary lockup carries no subtitle, and direction D is a fully integrated typemark.
</objective>

<beats>

<beat name="A — render directions + gallery" gate="autonomous">
Render, for each of the four directions, a transparent logomark SVG and a horizontal lockup SVG (mark + tight "Relyra" wordmark, no subtitle) under `brandbook/assets/logo-lab/`. Primary form uses `currentColor` so mono/inverse are trivial; at most one locked accent hex per direction. Then build `brandbook/logo-lab.html` (scoped CSS, opens from file://) showing all four directions at ~16/24/48/96px in a color row, a mono row, and an inverse-on-dark row, each labelled A/B/C/D with a one-line rationale.
Acceptance: 8+ SVGs exist with no `<rect>` background; `logo-lab.html` references each; opening it shows four clearly-labelled directions.
</beat>

<checkpoint>
STOP. Maintainer opens `brandbook/logo-lab.html` and picks ONE direction (A/B/C/D). Record the choice. Do not proceed to beat B without it.
</checkpoint>

<beat name="B — develop winner + usage rules" gate="after-selection">
Promote the chosen direction to `brandbook/assets/` as the full set: `logo-primary.svg` (horizontal, no subtitle), `logo-stacked.svg`, `logo-mark.svg`, `logo-mark-mono.svg`, `logo-primary-inverse.svg`, `favicon.svg` (simplified for 16/24px), `logo-with-tagline.svg` (separate, optional), `logo-typemark.svg` (integrated typemark variant). Write `brandbook/notes/logo-options.md`: rationale for why this direction won + the rejected three, and the usage rules (clear-space = cap-height of R; min sizes 120px lockup / 24px mark / 16px favicon; approved colorways; mark↔logotype spacing; misuse don'ts: no cage, no stretch, no separating mark/type, no low-contrast bg, no shadows, no subtitle on primary, no forbidden imagery).
Acceptance: full set present; favicon legible at 16px; logo-options.md covers rationale + all usage rules; LOGO-01/02/03 satisfied.
</beat>
