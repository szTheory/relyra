Enterprise SAML,
calmly verified.

Relyra is a strict-by-default SAML 2.0 service-provider library for Elixir and Phoenix. Every login ends in a cryptographically verified assertion or a typed rejection — never a silent compromise. Signatures are checked against the certificates you configure, not the ones an attacker can put in the document.

Get started Read the docs

Strict by default

The secure path is the default path. The digest is recomputed and the signature verified on every response — there is no setting that turns acceptance into structure-only.

Phoenix-native

Plugs, behaviours, and Ecto-backed stores that fit the app you already have. Connection resolution, session, user mapping, and replay are seams you implement, not internals you fight.

Explainable by design

Rejections are typed and specific, and every trust mutation co-commits an audit row. When a login fails, you can say exactly which check rejected it and why.
