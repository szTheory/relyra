06 Microcopy & Voice

Calm · exact · transparent

Relyra speaks like a careful operator: it states what happened, why it matters, and what to do next. It never over-promises security and never trivializes SAML.

Do / Don't copy pairs

✓ Do — exact

“Signature verified against the configured IdP certificate.”

✕ Don't — vague

“Login looks good!”

✓ Do — transparent

“Rejected: the assertion's Audience did not match this SP.”

✕ Don't — opaque

“Something went wrong. Try again.”

✓ Do — calm

“Replay protection is required in production. Configure an Ecto replay store before deploying.”

✕ Don't — alarmist

“DANGER!! Your app is WIDE OPEN to attackers!!”

The error pattern

Every rejection answers three questions in order: what happened · why it matters · what to do next.

What happenedThe assertion's Recipient was https://sp.example.com/acs, but this SP's ACS URL is https://sp.example.com/saml/acs. Why it mattersA mismatched Recipient can indicate a misdirected or replayed response, so Relyra refuses it rather than establishing a session. What to do nextAlign the IdP's ACS endpoint with the SP's configured acs_url, or update acs_url to match the registered endpoint.

Forbidden claims — never ship these

Relyra is never described as “unhackable,” “bulletproof,” “military-grade,” or “zero-risk,” and SAML is never called “easy.” Claims are specific and falsifiable, or they are not made.

07 For Developers

Consume the tokens

This page dogfoods tokens/tokens.css directly. Link it, reference --rl-* custom properties, and wire the theme hook. Hardcode nothing.

1 · Link the stylesheet

<link rel="stylesheet" href="tokens/tokens.css">

2 · Reference semantic vars

.button {
  background: var(--rl-action);
  color: var(--rl-bg);
  border-radius: var(--rl-radius-sm);
}

3 · Theme hook

/* tokens.css already ships both: */
[data-theme="dark"] { /* manual, wins */ }
@media (prefers-color-scheme: dark) {
  :root:not([data-theme="light"]) { … }
}

4 · Focus ring (never remove)

:focus-visible {
  outline: var(--rl-focus-width)
           var(--rl-focus-style)
           var(--rl-focus);
  outline-offset: var(--rl-focus-offset);
}
